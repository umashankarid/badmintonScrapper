Email Configuration (Brevo API)

📋 SMTP Setup Instructions

Setup with Brevo (Free - 300 emails/day)

  1. Create a free account at brevo.com
  2. Go to Settings → SMTP & API (direct link)
  3. Click Generate a new SMTP key or use existing one
  4. Copy the SMTP key (looks like: xkeysib-abc123...)
  5. In the form above:
    • Sender Email: the email you verified in Brevo (e.g. your Gmail)
    • API Key: paste the SMTP key
  6. Important: You must verify your sender email in Brevo:
    Go to Senders & IPs → Add a sender → Verify your email
✅ Why Brevo API? Render (and many cloud hosts) block SMTP ports (587, 465). Brevo's API uses HTTPS (port 443) which is always allowed.
