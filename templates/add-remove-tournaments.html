Available Tournaments from Badminton Sweden

Check the tournaments you want to appear in the available tournaments list for the players.

How Groups Work
Player Tournament WITH groups Tournament with NO groups
Player in groups LEVEL_2, JUNIOR Sees it if LEVEL_2 or JUNIOR matches Hidden
Player with no groups Hidden Sees it
Admin Sees all Sees all

Examples:

  • Komet Hösttävling with groups LEVEL_2, LEVEL_5 → Only players in LEVEL_2 or LEVEL_5 will see it.
  • Vikingaslaget with groups SENIOR, LEVEL_6 → Only players in SENIOR or LEVEL_6 will see it.
  • Spånga Open with no groups → Only players who have no groups assigned will see it.
  • Träningscup with groups JUNIOR → Only players in JUNIOR group will see it.

Tip: Hold Ctrl/Cmd to select multiple groups. To deselect all groups, hold Ctrl/Cmd and click the selected group(s).
